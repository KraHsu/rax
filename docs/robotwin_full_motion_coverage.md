# 全时段监督，普通移动只约束方向

每条成功轨迹的每个有效 action 帧、每条机械臂，都必须有一项在当前 chunk 内可计算的位置或运动约束。帧 0 是初始状态，不是预测动作。全时段覆盖不意味着把全部自由度锁到示范上；朝向和夹爪覆盖单独统计，不能用它们冒充移动监督。

之前只有事件、终点和夹爪保持区间，不能满足该要求。发布与训练初始化现在都会检查覆盖。

## 方向损失

2026-10-30 的本地修复增加 schema 1.3 / motion policy v3 的
`window_direction_cone`。旧数据里的 `motion_direction_cone` 保持原公式；
没有自动重标或修改当前评测的数据。以下相邻差分公式描述旧版本：

```
v[t] = p[t] - p[t-1]
a = dot(n, v[t])
b = norm(v[t] - a*n)
f = max(0, b - tan(alpha)*a, -a)
loss = (max(0, f - slack_m) / scale_m) ** 2
```

方向锥半角默认 60°，允许 0.1 mm 的死区，损失尺度 5 mm。不同路径、步长和方向锥内的横向变化均可接受；整个路径平移后损失不变。普通移动没有逐帧 XYZ 目标。明显侧偏或反向移动才产生惩罚。零位移也被允许，方向监督本身不保证到达，仍需任务终点/交互区域及基础 BC/FM 损失。记录间隔不被假设为固定物理时间。

参考发生转向或停顿时分段，激活不依赖预测。已有任务相关位置/轴向/事件约束优先，自动补全只填其余位置/运动监督空缺。静止段使用参考静止范围加 20 mm 的保持区域；参考步长 ≤0.01 mm 视为静止。不会为了凑覆盖率添加无依据的姿态要求。

以上是明确的初始先验，记录于 `full_trajectory.POLICY` 与 HDF5 覆盖审计，不是已验证的物理成功范围。

新版本把 `v[t]` 改为同一参考运动段内最多 8 步的净位移
`p[t]-p[max(t-8, segment_start-1, chunk_start)]`。方向锥不要求
非零预测运动，也不新增速度或任务进展要求。参考转弯/停顿会分段，窗口
不能跨这些边界。窗口至少 2 步且参考净位移至少 5 mm 才使用方向损失。

chunk 首端、短段或参考净位移不足时，使用该段**固定的整段参考位置包围球
加 20 mm** 的越界损失。球心和半径作为数据参数保存，整个段共享，不随
每一帧的参考位置移动。这保证短 chunk 仍有可计算的位置先验，同时不回退
到敏感的一步差分。分支只根据参考轨迹和有效掩码选择，预测不能通过停止来
切换分支。该球域仍然只是未校准的运动正则，不能解释为无碰撞或高成功率区域。

新方向项解决相邻位置误差差分放大的问题，不补充抓取姿态、接触、物体目标、
双臂协同或先后事件的缺失监督。全覆盖始终仅表示时间覆盖，绝非成功充分性。

## Chunk 与数据

旧方向项第一项使用 chunk 初始状态与第一个预测位置；新方向项使用上面的
多步窗口和固定球域回退。无效维度、填充帧被排除；窗口跨过无效位置时使用
球域，不能用 NaN 填充构造位移。原有长跨度位移保留，但不能单独满足全覆盖检查。

- `complete_constraints` 保留原有任务约束，并补齐时段空缺。
- 复用模板的数值检查返回完整约束与覆盖报告。
- `embed_review` 和实时 `EpisodeRecorder.finish` 在发布前补全、验证，并写入 `trajectory_constraints/coverage`。
- `backfill_robotwin_motion_coverage.py` 使用复制、校验、原子替换补标已发布 HDF5，保留动作、图像、seed、场景和原有修订历史。重复运行跳过已完成记录。
- OpenWAM 默认 `training.constraints.require_full_coverage=true`，拒绝未覆盖轨迹。`false` 仅用于明确的稀疏消融/原语测试。
- 网站显示双臂位置/运动覆盖及缺口，单独显示朝向和夹爪比例，并自动刷新新修订。

```bash
python scripts/backfill_robotwin_motion_coverage.py --root /path/to/robotwin_clean50_v1
```

覆盖审计证明约束在时间和 chunk 上可计算，不证明任务成功或全部几何自由度均有界。训练损失仍作用于恢复出的干净动作估计，不运行仿真。
