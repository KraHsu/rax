## 如何阅读

主仓库的 `feat/robotwin-constraint-supervision` 保存数据录制、约束标注、模板、离线评分等实现；相应 OpenWAM 分支保存训练接入。其余独立修订仍在各自 feature/fix/codex 分支，未合并。本归档补充此前保存在工作区 `artifacts/constraint_refinement/` 下的独立研究源码。

这不是可直接运行的部署包。原输入数据、参考轨迹、逐条回放结果、冻结计划、资产、完整依赖快照、模型权重和服务器部署材料没有上传。部分脚本和测试依赖这些本地材料或原目录布局，不能仅凭此目录运行完整实验。完整证据与原文件继续保留在原工作区和服务器。

此处的有限验证、进程归属检查和实验准入机制是历史运行保护，不是研究目标、meta loss 的组成部分或任务成功证明。研究的核心问题仍是：如何在动作先验之上构造低成本、能可靠反映任务成功的代理，以及如何用反例改进它。现有结果尚未解决这个问题。

周期巡检已停止并禁用。后续是否恢复实验、调整目标或训练，由用户重新确定。
